## Экраны и оставшиеся демонстрационные файлы

Обзор, список направлений, страница темы и блок количества карточек в статистике читают Supabase. Тренировка явно недоступна и не записывает ответы или прогресс. Достижения и история занятий показывают временные пустые состояния.

Исходные `src/data/demo.ts`, `src/features/training/Training.tsx`, `src/features/dashboard/CreateTopicDialog.tsx` и компоненты старых диаграмм оставлены как исходный код прототипа для последующего этапа. Основные маршруты их не используют и демонстрационные данные пользователю не показывают.

## Как добавлять контент

После применения миграции прав создавайте **новую** SQL-миграцию для конкретного владельца. Укажите его UUID из Authentication → Users, задайте постоянные UUID для тем и карточек, применяйте `INSERT ... ON CONFLICT (id) DO UPDATE` с проверкой `user_id`. При обновлении текста сохраняйте UUID карточки, чтобы сохранить историю. Подробный шаблон: `supabase/content/README.md`. Дополнительные столбцы или таблицы для этого этапа не нужны.

## Ручное применение к удалённому проекту

Проверьте, что первые две миграции этапа 1 уже применены. Затем откройте SQL Editor в нужном проекте Supabase, просмотрите содержимое `supabase/migrations/20261109000100_content_read_only.sql` и выполните его вручную. Эта миграция меняет только права и политики; данные не удаляются. Если миграции ведутся через Supabase CLI, не выполняйте команду отправки всех ожидающих миграций без проверки списка.
