# Analysis: учебные карточки

Набор для подготовки к собеседованию на Product Engineer. Тема объединяет бизнес-анализ и системный анализ уровня middle/middle+: от выявления потребности и оценки ценности до системных контрактов, внедрения и проверки результата. Каждая подтема собрана в один YAML для последующего импорта.

| Подтема | Карточек | Файлы |
|---|---:|---|
| Выявление требований | 27 | [карточки](01-requirements-elicitation.yaml) |
| Функциональные требования | 28 | [карточки](02-functional-requirements.yaml) |
| Нефункциональные требования | 24 | [карточки](03-nonfunctional-requirements.yaml) |
| BPMN и бизнес-процессы | 26 | [карточки](04-bpmn-business-processes.yaml) |
| UML и поведение системы | 27 | [карточки](05-uml-system-behavior.yaml) |
| Моделирование данных | 28 | [карточки](06-data-modeling.yaml) |
| API-контракты | 32 | [карточки](07-api-contracts.yaml) |
| Интеграции | 34 | [карточки](08-integrations.yaml) |
| Декомпозиция и постановка задач | 26 | [карточки](09-decomposition-task-definition.yaml) |
| Проверка и управление требованиями | 28 | [карточки](10-requirements-validation-management.yaml) |
| Бизнес-цели и ценность | 26 | [карточки](11-business-goals-value.yaml) |
| Улучшение бизнес-процессов | 23 | [карточки](12-business-process-improvement.yaml) |
| Стейкхолдеры и оценка решения | 25 | [карточки](13-stakeholders-solution-evaluation.yaml) |

**Итого:** 354 карточки. Количество в каждой подтеме определяется значимым покрытием, а не фиксированной квотой.

При составлении использованы [матрица Product Engineer](../../../product-engineer-seniority-matrix/common-skills/BRPE.md), [стандарт бизнес-анализа IIBA](https://www.iiba.org/knowledgehub/business-analysis-standard/4-tasks-and-knowledge-areas/introducing-business-analysis-tasks), [BABOK](https://www.iiba.org/career-resources/a-business-analysis-professionals-foundation-for-success/babok), [BPMN](https://www.omg.org/bpmn/), [UML](https://www.omg.org/uml/), [OpenAPI](https://spec.openapis.org/oas/), [HTTP Semantics](https://www.rfc-editor.org/rfc/rfc9110.html) и [российская подборка вопросов по системному анализу](https://habr.com/ru/articles/815395/).
