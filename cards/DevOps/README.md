# DevOps: учебные карточки

Набор для подготовки Product Engineer уровня middle/middle+ к самостоятельной сборке, развёртыванию и сопровождению Java-сервиса. Каждая подтема собрана в один YAML для последующего импорта.

| Подтема | Карточек | Файлы |
|---|---:|---|
| Linux: процессы, файлы и диагностика | 26 | [карточки](01-linux-processes-files.yaml) |
| Сети, HTTP, DNS и TLS | 24 | [карточки](02-networking-http-dns-tls.yaml) |
| Docker и контейнерные образы | 26 | [карточки](03-docker-containers-images.yaml) |
| Kubernetes: workloads и жизненный цикл | 28 | [карточки](04-kubernetes-workloads.yaml) |
| Kubernetes: сеть, хранение и доступ | 25 | [карточки](05-kubernetes-network-storage-security.yaml) |
| CI/CD и выпуск изменений | 29 | [карточки](06-ci-cd-releases.yaml) |
| Helm и конфигурация приложения | 24 | [карточки](07-helm-configuration.yaml) |
| Секреты, права и безопасность поставки | 24 | [карточки](08-secrets-access-security.yaml) |
| Наблюдаемость: метрики, логи и трассировка | 30 | [карточки](09-observability.yaml) |
| Диагностика, инциденты и восстановление | 28 | [карточки](10-troubleshooting-incidents.yaml) |
| Infrastructure as Code и автоматизация | 22 | [карточки](11-infrastructure-as-code.yaml) |

**Итого:** 286 карточек. В каждой подтеме не более 40; число определялось покрытием, а не квотой.

При составлении использованы [матрица Product Engineer](../../../product-engineer-seniority-matrix/common-skills/IDPE.md), [Kubernetes Docs](https://kubernetes.io/docs/), [Docker Docs](https://docs.docker.com/), [Helm Docs](https://helm.sh/docs/), [Prometheus Docs](https://prometheus.io/docs/), [Terraform Docs](https://developer.hashicorp.com/terraform/docs), [Ansible Docs](https://docs.ansible.com/) и [подборка вопросов к собеседованию разработчика по Kubernetes](https://habr.com/ru/companies/mws/articles/719198/).
