# Testing: учебные карточки

Набор для подготовки Product Engineer уровня middle/middle+ к проверке Java/Spring-сервиса от бизнес-правила до релиза. Каждая подтема собрана в один YAML для последующего импорта.

| Подтема | Карточек | Файлы |
|---|---:|---|
| Стратегия и уровни тестирования | 24 | [карточки](01-testing-strategy-levels.yaml) |
| Тест-дизайн и покрытие | 28 | [карточки](02-test-design.yaml) |
| Unit-тесты и JUnit | 27 | [карточки](03-junit-unit-tests.yaml) |
| Mockito и тестовые двойники | 27 | [карточки](04-mockito-test-doubles.yaml) |
| Интеграционные тесты и Testcontainers | 32 | [карточки](05-integration-testcontainers.yaml) |
| API и контрактное тестирование | 28 | [карточки](06-api-contract-testing.yaml) |
| E2E и системное тестирование | 24 | [карточки](07-e2e-system-testing.yaml) |
| Тестовые данные и окружения | 24 | [карточки](08-test-data-environments.yaml) |
| Нефункциональное тестирование и производительность | 26 | [карточки](09-nonfunctional-performance.yaml) |
| Качество релизов, дефекты и QA-процесс | 28 | [карточки](10-quality-release-defects.yaml) |

**Итого:** 268 карточек. В каждой подтеме не более 40; количество определялось покрытием значимых вопросов.

При составлении использованы [матрица Product Engineer](../../../product-engineer-seniority-matrix/common-skills/QAPE.md), [ISTQB](https://www.istqb.org/certifications/certified-tester-foundation-level), [JUnit](https://docs.junit.org/), [Mockito](https://site.mockito.org/), [Spring Boot Testing](https://docs.spring.io/spring-boot/how-to/testing.html), [Testcontainers](https://java.testcontainers.org/), [Spring Cloud Contract](https://docs.spring.io/spring-cloud-contract/docs/current/reference/html/README.html) и [k6](https://grafana.com/docs/k6/latest/).
