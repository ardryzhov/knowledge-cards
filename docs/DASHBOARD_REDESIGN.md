# Редизайн Dashboard

Визуальный референс: [terminal_trainer.png](../img_tmp/terminal_trainer.png). Реализован редизайн в рамках текущего демонстрационного приложения.

## Главная страница

Сохранены утверждённые цвета и Geist Mono, тонкие контуры, синий и зелёный градиенты. Убраны дополнительные декоративные элементы и большой приветственный текст. Порядок блоков соответствует текстовому заданию:

1. Компактный заголовок «Знания — твой актив».
2. Уровень, XP, недельный прирост и прогресс.
3. Три метрики: выучено, точность и дни подряд.
4. Готовые к повторению карточки и основная кнопка тренировки.
5. Компактные горизонтальные строки направлений.
6. Одно последнее достижение и переход к полному списку.

Число выученных и готовых к повторению карточек агрегируется из демонстрационных тем. Остальные показатели остаются демонстрационными. На главной сохранена явная отметка о демо-данных в подвале.

## Переходы и сохранение функций

Существующие `#dashboard`, `#training`, `#training?topic=...` и `#statistics` сохранены.

Страниц тем и достижений в исходном прототипе не было. Для требуемых переходов добавлены минимальные страницы демо-просмотра:

- `#topics` — все направления.
- `#topics/development`, `#topics/english`, `#topics/devops` — страница темы с прогрессом, примерами карточек и запуском существующей тренировки по теме.
- `#achievements` — все три существовавших демо-достижения с условиями, датами и прогрессом.

Клик по строке направления открывает тему. Основная кнопка запускает тренировку. Метрики ведут в статистику. Последнее достижение и ссылка «Все» открывают страницу достижений.

Большие графики и расширенные показатели остаются на Statistics. Блок «Фокус недели» с календарём по дням перенесён с главной туда же. График активности на Statistics уже существовал и сохранён. Полноценного месячного календаря в исходном прототипе не было; новый механизм календаря не добавлялся.

Список достижений и ранее доступные через раскрытие условия и даты теперь находятся на отдельной странице. CRUD, серверные операции и новые учебные алгоритмы не добавлялись.

## Мобильная компоновка и состояния

- На iPhone контент главной прокручивается в отдельной области над нижней навигацией; панель не перекрывает карточки.
- Учтены `safe-area-inset-top/right/bottom/left` и доступная высота viewport.
- Сохранены существующие три пункта нижней навигации.
- Названия тем переносятся, описания сокращаются многоточием и доступны полностью в `title`.
- Пустые направления и достижения имеют отдельные сообщения. Без доступных карточек счётчик повторения равен нулю, кнопка запуска отключена.
- Неизвестная тема показывает сообщение и ссылку на направления. Тема без примеров карточек не предлагает недоступную тренировку.

## Проверки

- `npm run typecheck` — успешно.
- `npm run lint` — успешно, без предупреждений.
- `npm run build` — успешно.
- `npx playwright test` — 40 проверок в Chromium и WebKit с профилем iPhone 13: новые сценарии Dashboard и регрессии существующих экранов.
- Проверены ширины 320/375/390/430/768/1024/1440 px, отсутствие горизонтального скролла, порядок блоков, три метрики и одно достижение.
- Проверены все направления, кнопка общей тренировки, запуск по теме, переходы в статистику и достижения, возврат, неизвестная тема.
- Длинное название с большой последовательностью символов без пробелов проверено при ширине 320 px.
- Пустые состояния проверены рендером самих компонентов с пустыми входными данными, без изменения данных приложения.
- Проверено, что прокручиваемая область заканчивается над навигацией, а последнее достижение можно полностью увидеть и нажать.
- Скриншоты сохранены и просмотрены.

ESLint прежде не был настроен. Для выполнения запрошенной проверки добавлены только инструменты разработки: ESLint, конфигурация JavaScript/TypeScript, React Hooks и globals. Новые библиотеки для работающего в браузере приложения не устанавливались.

Дополнительная проверка npm audit сообщает о 11 moderate-предупреждениях в цепочке инструментов lint, связанных с minimatch. Затронутый пакет помечен как dev dependency. Audit не предлагает совместимого исправления без смены основных версий; принудительная смена версий не выполнялась.
