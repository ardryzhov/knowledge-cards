# Отчёт по этапу 0

Реализован визуальный прототип Knowledge Cards из раздела 16 AGENT_PLAN.md. Следующий этап не начат.

## Реализовано

- Dashboard: уровень, XP, серия занятий, количество карточек, освоение, точность, график активности, три направления и три демо-достижения.
- Training: выбор темы, две последовательные подсказки, таймер 30/60/120 секунд или без ограничения, 3D-переворот, доступная после открытия ответа оценка кнопками или свайпом, завершение и перезапуск сессии.
- Statistics: фильтры 7/30 дней и двух режимов, метрики, график ответов, динамика точности, прогресс направлений и статусы карточек.
- Навигация на desktop и mobile, safe-area, focus-visible, пропуск к содержимому, доступные подписи, поддержка prefers-reduced-motion.
- Цвета и градиенты из раздела 3 вынесены в CSS-токены. Geist Mono и Geist загружаются локально.

## Проверки

- TypeScript strict: `npm run typecheck`.
- Production build: `npm run build`.
- Браузерные сценарии: `npm run test:e2e`, Chromium и WebKit/iPhone 13 — **18 из 18 пройдены** на production-сборке.
- Все три экрана проверяются на ширинах 320/375/390/430/768/1024/1440 px: отсутствие горизонтального переполнения и ошибок JavaScript.
- Проверяются переходы, выбор темы, подсказки, недоступность оценки до ответа, итог и перезапуск, истечение и остановка таймера, фильтры, reduced motion, горизонтальный свайп и независимость вертикальной прокрутки от оценки.
- Сохранены и просмотрены скриншоты интерфейса.

Тесты запускаются на production-сборке. Lint ещё не настроен: он относится к этапу 1. Физический iPhone не использовался; WebKit и синтетические Pointer Events не заменяют проверку нативного жеста на устройстве.

## Решения и ограничения

- Данные явно демонстрационные. Метрики не выдают демо-активность за сохранённое обучение.
- UI-состояние тренировки существует только в памяти. Supabase, хранилище и учебные алгоритмы не подключались.
- Вместо полной маршрутизации используются hash-переходы между тремя экранами; React Router запланирован на этапе 1.
- Короткая последовательность демонстрационных карточек одинакова для двух режимов. Это не интервальный и не бесконечный алгоритм.
- Пример награды XP на итоговом экране статичен и помечен DEMO; настоящая система наград не реализована.
- Большие графические библиотеки выделены в отдельные chunks, подключены только кириллические и латинские наборы используемых шрифтов.
- Публикация не выполнялась: в ТЗ она запланирована на этапе 9.

## Что осталось и решение пользователя

Согласовать дизайн трёх экранов и при необходимости внести визуальные правки в рамках этапа 0. Переход к этапу 1 — только после подтверждения пользователя.
